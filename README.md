# 🌟 Olivier Trevis — Site Officiel

Site officiel d'Olivier Trevis, acteur local, associatif et événementiel basé à **Dour, Belgique**.

## 📋 Description

Plateforme complète pour les projets, ASBL, événements et initiatives locales d'Olivier Trevis autour de Dour.

## 🗂️ Pages

| Page | Route | Description |
|------|-------|-------------|
| Accueil | `/` | Hero, projets phares, vidéos, actualités |
| À propos | `/a-propos` | Portrait, valeurs, rôles associatifs |
| ASBL & Projets | `/asbl` | Fiches associations avec modal détaillé |
| Miss & Mister Dour | `/miss-mister-dour` | Concours Fashionist'ART complet |
| Tour de Dour | `/tour-de-dour` | Vidéos, visites, reportages locaux |
| Vidéos | `/videos` | Médiathèque YouTube avec filtres |
| Actualités | `/actualites` | Blog & annonces |
| Galerie | `/galerie` | Photos avec lightbox |
| Partenaires | `/partenaires` | Sponsors & collaborateurs |
| Contact | `/contact` | Formulaire multi-objet |
| Mentions légales | `/mentions-legales` | RGPD, CGU, droits d'image |
| **Admin** | `/admin` | Dashboard de gestion complet |

## 🎨 Stack Technique

- **Frontend** : React + Vite
- **Style** : Tailwind CSS + Framer Motion
- **Backend/DB** : Base44 (entités, API)
- **Storage** : Supabase (vidéos & visuels)
- **Design** : Noir / Doré / Rouge

## 🗃️ Entités de données

- `Asbl` — Associations et projets
- `Evenement` — Événements
- `Video` — Vidéos YouTube
- `Actualite` — Blog & actualités
- `Photo` — Galerie photos
- `Partenaire` — Partenaires & sponsors
- `Candidature` — Inscriptions concours
- `MessageContact` — Messages reçus
- `Laureat` — Lauréats des concours

## 🚀 Développement local

```bash
npm install
npm run dev
```
