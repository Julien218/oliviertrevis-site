# oliviertrevis.be — Site officiel

Site officiel d'**Olivier Trevis**, acteur local, associatif et événementiel basé à **Dour, Belgique**.

## 🏗️ Stack technique

- **React** + **React Router** — SPA multi-pages
- **Tailwind CSS** — Design system
- **Framer Motion** — Animations
- **Base44** — Backend, DB, authentification, storage
- **Supabase** — Storage vidéos & médias (à venir)
